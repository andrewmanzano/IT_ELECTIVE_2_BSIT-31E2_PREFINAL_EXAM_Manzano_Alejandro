Section: BSIT-31E2

About the Project:
This project is an ASP.NET MVC application created for the IT Elective 2 Pre-Final Examination.
The application displays 20 multiple-choice questions with four choices for each question: A, B, C, and D.

Features:
- 20 examination questions
- Four choices for every question
- Displays the selected/correct answer
- MVC architecture
- No database required
- Simple and creative user interface


Project Structure:
Models - Question.cs
Controller - QuestionController.cs
Views/Question - Index.cshtml
Views/Shared - Layout.cshtml
